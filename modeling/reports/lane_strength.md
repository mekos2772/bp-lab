# 对线强度（15 分钟经济差）— 与胜率分离的强度指标

生成时间：2026-11-12

## 为什么单独做「强度」

用户的原话：**“胜率和强度要分开，强度是一眼能看出来的，比如 EZ 卡尔玛前期比霞洛强。”**

- **胜率**：历史结果统计，弱先验（职业 8,800 局 AUC 0.515）。
- **强度**：对线期的作战能力，可以用「15 分钟经济差」直接测量，不需要胜率。

## 数据

- 来源：ChainCC 2026（CC BY 4.0），职业赛逐选手逐局。
- 指标：`golddiffat15`（相对同路对手），按 (patch, role) 去均值。
- 两种粒度：
  - 单人：英雄-分路，n ≥ 20（142 英雄 / 202 个分路条目）。
  - 下路双人：同一局 ADC+辅助合计，n ≥ 10（239 个组合）。

## 用户举的例子

| 组合 | 场次 | 15′ 经济差（合计） | 95% CI |
|---|---|---|---|
| **伊泽瑞尔 + 卡尔玛** | 536 | **+239.7** | 86.4 ~ 366.8 |
| **霞 + 洛** | 426 | **+90.6** | −64.9 ~ 235.7 |

结论：EZ+Karma 的对线经济优势确实更高（+149），与“前期更强”的直觉一致；
但两者 CI 有重叠，所以产品上标「略强」而不是「强」。

## 产品接入

分析区新增「对线强度 · 15 分钟经济差（职业赛 2026）」：

```
上单  杰斯 +509.2  vs  墨菲特 −571.9   → 强 +1081 (n 161)
下路  双人合计 +239.7 vs 霞洛 +90.6     → 略强 +149 (n 426)
```

标签规则（写死在代码里，透明）：

```text
delta ≥ +200 → 强      +100 ~ +200 → 略强
−100 ~ +100 → 均势
−200 ~ −100 → 略弱    ≤ −200 → 弱
```

只有双方同一位置都选齐才显示；下路用双人合计，其他位置用同位置。

## 与旧「强度曲线」的区别

| | 旧曲线（已下线） | 现在的对线强度 |
|---|---|---|
| 测量对象 | 最终比赛时长的条件胜率 | 15 分钟经济差 |
| 是否胜率 | 是（条件胜率） | 否（经济差） |
| 是否可预测 | 否（校验相关 ≈0） | 不用于预测，只描述对线期 |
| 样本量 | 无 | 每项都带 n 与 CI |
