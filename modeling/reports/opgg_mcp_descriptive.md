## 数据限制

- OP.GG MCP 没有 `region` 参数，当前为默认区域聚合，不能保证是韩服 KR。
- OP.GG MCP 没有游戏时长桶；时长曲线来自旧的 OP.GG 网页快照。
- `summary.winRate` 是页面级汇总，按样本量近似还原 wins；不是逐局复算。
- Pair `winRate` 是原始双人胜率，不是扣主效应后的协同残差。
- 低样本桶/组合必须显示 `n` 与 CI，不能按排名直接比较。
