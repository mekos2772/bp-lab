# 真实 BP 顺序回测（LoL-Draft 2026）

生成时间：2026-11-12

## 数据

- 来源：**LoL-Draft**（GitHub `DeusExMachina1993/LoL-Draft`，CC BY-SA 4.0），源自 Leaguepedia。
- 文件：`2026/all_patches/all_patches.inter`（176,960 行 = **8,848 场** × 20 手）。
- 结构：每场两个 user（两队），各 10 行（5 ban + 5 pick），`timestamp` 为全局操作序号；合并两 user 即得**真实 20 手顺序**。
- 字段：`item_id` / `hero_name` / `action_type` / `patch` / `team_result` / `first_team`。
- 限制：**没有位置字段**，回测用「英雄最热门分路」近似；这是近似，不是真实分路。

## 回测协议

按真实顺序逐手推进；每次 `pick` 动作发生时，在「未被 ban、未被选」的合法集合上排序，记录真实英雄的名次。

| 模型 | 分数来源 |
|---|---|
| M0 随机 | 理论值 |
| M1 快照热门度 | OP.GG 16.22 分路选取率（跨补丁使用，口径不匹配） |
| M1′ 同补丁经验热门 | 同一补丁内其他对局的英雄出场频率（leave-one-game-out） |
| M2′ 经验 + 版本 | M1′ + 梯队/排名/胜率 |
| M3′ 经验 + 上下文 | 0.8 × 经验热门 + 0.2 × 适配度（缺口/协同/对位/伤害） |

## 结果（88,442 次 pick）

| 模型 | Top1 | Top3 | Top5 | MRR |
|---|---|---|---|---|
| M1 快照热门度（跨补丁） | 1.2% | 3.4% | 8.0% | 0.062 |
| **M1′ 同补丁经验热门** | **4.7%** | **12.5%** | **19.2%** | **0.142** |
| M2′ 经验 + 版本 | 4.7% | 12.5% | 19.2% | 0.142 |
| M3′ 经验 + 上下文 | 4.7% | 12.5% | 19.2% | 0.142 |
| M0 随机 | — | — | 3.1% | — |

按补丁 Top5：2612 16.6% / 2613 19.2% / 2614 19.8% / 2615 18.0% / 2616 17.8% / 2617 18.7%。

## 结论

1. **唯一有验证的预测信号是「同补丁的出场频率」**：Top5 19.2%，是随机的 6 倍。
2. **版本表现与适配度（缺口/协同/对位/伤害）没有带来可测量的增量**（≤0.1pp，部分补丁还略低）。
3. 用跨补丁的单一快照（16.22 选取率）预测全年比赛，Top5 只有 8.0%——**口径不匹配会严重掉点**，这解释了之前排位实验里"热门度主导"的现象。
4. 因此：候选排序应以「同补丁出场频率」为基线；适配项只能作为解释，不能声称提升预测。

## 局限

- 数据无位置，回测用最热门分路近似，会低估纯位置特征的价值。
- 只有职业比赛，不能直接外推到排位（但排位没有真实 BP 顺序）。
- 经验热门度是 in-sample 统计（同补丁其他对局），未做时间前向切分，可能略高估；正式评估应按时间切分训练/测试。
