# 阶段倾向曲线：标签扩展、校准与验证（2026-11-12 更新）

## 0. 本次做了什么

把英雄标签从 **59 个** 扩到 **173 个全覆盖**（DDragon 技能文本 + 规则 + 机械校验），
再用职业赛 15 分钟经济差重新校准「早期」权重。

## 1. 标签生产

| 项 | 数值 |
|---|---|
| 合约英雄 | 173 |
| 原有标签 | 59（57 人工 REVIEWED + 2 新英雄待补） |
| 新标注 | **116**（4 批，DDragon 技能摘要 + `docs/traits_rubric.md`） |
| 合并后 | 57 REVIEWED + 116 SPOT_CHECKED = **173 全覆盖，0 未审维度** |
| 校验 | `scripts/qa_traits.py`：0 错误（10 维齐全、STRONG ≤3、远程非坦前排规则、硬案例） |

标注口径（写进 rubric）：

- 禁锢/沉默/恐惧/魅惑都算硬控；减速、位移、拉拽不算。
- 自我回复不算 `peel`；远程（attackrange>500）非 Tank 不得 `frontline=STRONG`。
- 单英雄 STRONG ≤ 3。

**诚实说明**：116 个新标签是 LLM 依据 DDragon 文本 + 规则生成的 `SPOT_CHECKED`，
不是逐个英雄的人工复核；`evidence` 里都点名了技能，可用 `data/labels/merged_v3.json` 追溯。

## 2. 早期校准（目标：15 分钟经济差）

样本：`lane_stats` 中 n≥20 且标签齐全的 **202 个英雄-分路 / 140 个英雄**。

| 模型 | 按英雄分组 5 折 CV corr |
|---|---|
| 旧专家权重 | −0.066 |
| 旧校准（84 样本，10 维） | 0.298 |
| 10 维岭回归（202 样本） | 0.323（bootstrap 95% CI 0.142~0.448） |
| **稳定 6 维岭回归（生产版）** | **0.374** |

最终权重（正 = 前期更强，ridge l2=30，按 |w| 归一化）：

| 维度 | 权重 |
|---|---|
| scaling 成长 | **−81.2** |
| frontline 前排 | **−91.6** |
| engage 开团 | **−53.6** |
| waveclear 清线 | −43.1 |
| burst 爆发 | **+36.5** |
| splitpush 分推 | **+50.0** |

剔除 `poke / peel / dps / dive`：bootstrap 符号翻转 >30%，加入后 CV 不升反降。

队伍级校验（ChainCC teams，9,901 局，双方阵容都可评）：

| 权重 | corr(早期分差, team golddiff@15 差) |
|---|---|
| 旧专家 | −0.003 |
| 旧校准 | 0.123（在扩展样本上） |
| **新 6 维** | **0.148** |

## 3. 早/中/后期方向性检验（12,523 局职业赛）

按最终时长分组，看「早期分差」与胜负的相关：

| 时长 | corr(早期分差, 胜) | n |
|---|---|---|
| < 25 分钟 | **+0.174** | 1,545 |
| 25–35 分钟 | +0.029 | 8,088 |
| ≥ 35 分钟 | **−0.030** | 2,890 |

这是本次最像“验证成功”的结果：**早期型阵容确实在短局赢得更多，长局反而略吃亏**。
方向和幅度都符合“阶段倾向”的预期（长局效应仍很弱）。

## 4. 验收结论

| 验收项 | 目标 | 实际 | 判定 |
|---|---|---|---|
| 标签覆盖 | 173 全有结论 | 173 / 173，0 未审 | ✅ |
| 机械 QA | 0 错误 | 0 错误 | ✅ |
| 早期 CV corr | ≥ 0.30 | **0.374** | ✅ |
| 队伍级 corr | ≥ 0.16 | **0.148** | ⚠️ 未达 |
| 硬案例 | 不漂移 | 通过 | ✅ |

队伍级 0.148 未到 0.16 的原目标；但该目标是在旧 84 样本上定的，**同口径对比**
旧权重在扩展样本上只有 0.123，新权重 0.148 是提升的。是否接受 0.148 作为新基线，需要产品决定。

## 5. 局限

- 新标签由 LLM 起草 + 机械校验，不是逐英雄人工复核；争议口径（拉拽/击退、新英雄）已记录在 evidence。
- 15′ 经济差未控制打野游走、选手水平、对位克制，相关性不等于因果。
- 中后期仍无分钟级数据，不能验证“某分钟达到峰值”。
- 校准样本 202 个英雄-分路、140 个英雄，bootstrap CI 仍较宽（0.142~0.448）。
